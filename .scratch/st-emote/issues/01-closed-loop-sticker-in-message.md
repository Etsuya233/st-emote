# 01 — 闭环：一张表情能在消息里出现

**What to build:** 装上扩展后，用户能新建一个表情包、上传一张（或多张）图片、逐张填标签，把包在全局启用，然后让 AI 回复里出现 `[[sticker:标签]]` —— 那个位置就出现对应的图片。这是整套东西里最小但完整的一条路径：扩展骨架、面板、上传、标签、全局作用域、原地投放、渲染、未命中处理、测试基座一次到位。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 扩展能被 ST 加载并出现在扩展列表里；设置面板里能看到表情包区域并展开
- [x] 能新建表情包，一次选中多张本地图片上传进去，并逐张填写标签
- [x] 全局启用该包后，AI 回复里的 `[[sticker:标签]]` 在屏幕上显示为对应图片，且在流式生成结束后位置稳定
- [x] 标签不存在、包未启用、图片缺失时，标记从显示中消失，控制台留有一条记录
- [x] 纯核心（标记解析、生效集解析、渲染拼装）有可运行的测试，覆盖命中与未命中两类
