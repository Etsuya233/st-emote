# 04 — 投放方式与尺寸

**What to build:** 用户能决定图出现在哪里（原地 / 段后 / 消息末尾，可对单张表情单独覆盖），也能分别控制 inline 与 block 两种场景下的尺寸与填充方式，包括填错时的提示与不留配置时的默认表现。

**Blocked by:** 01 — 闭环：一张表情能在消息里出现

**Status:** ready-for-agent

- [ ] 三种投放方式都落在预期位置："块后"落在当前段与下一段之间（段落、列表项、引用块、标题、表格单元按最近的块级容器取，断行不算块）
- [ ] 可以为单张表情覆盖全局的投放方式；覆盖后使用对应的那套尺寸配置
- [ ] inline 与 block 两套都能设置最小/最大宽高与 `cover` / `contain` / `fill`；`em` / `px` / `%` 手写可用
- [ ] 非法尺寸值被当作未设置，并在输入框旁给出可见提示，不阻止继续编辑
- [ ] 未填任何值时使用默认值（inline 默认 `max-height: 3em`，block 默认 `max-width: 100%`），1024px 级的图不会撑破版面
- [ ] 块级语境下一条消息里的多张图各自成块、竖排
- [ ] 流式生成过程中标记一写完整就出图；改任何设置后当前聊天立刻重渲染
