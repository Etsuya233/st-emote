# 02 — 规则完整：语法、约束、处理范围

**What to build:** 标记的写法和输入规则按规格收口。用户能用两种标记形态、能在多包与单包下都写对名字；会破坏语法的输入在填写时就被拦下；不该被渲染的地方（代码块、系统/旁白、思考链、用户消息）保持原样。

**Blocked by:** 01 — 闭环：一张表情能在消息里出现

**Status:** ready-for-agent

- [ ] 多个包同时启用时 `[[sticker:包名:标签]]` 正确命中；只启用一个包时，裸标签 `[[sticker:标签]]` 与带前缀写法都能命中；多包时裸标签算未命中
- [ ] `<sticker>…</sticker>` 形态可用：在用户的 HTML 转义开关打开与关闭两种情况下都能渲染；标签名可配置，配置成真实 HTML 标签名时被拒绝
- [ ] 标签超长、含 `[` `]` `<` `>`、描述换行、包名含 `:` 时，输入被拦下并说明原因
- [ ] 同一个包内两张表情同名被拦下；新建或改名导致包名全应用重复被拦下（不自动加后缀）
- [ ] 没填标签的表情不出现在清单里、不参与匹配，界面上标为「待填标签」；描述允许留空，界面显示为「—」
- [ ] 代码块与行内代码里的标记不渲染；用户消息默认不渲染（有开关可打开）；系统/旁白消息与思考链不渲染
- [ ] 同一条消息里同一个标记出现两次就出现两张图
