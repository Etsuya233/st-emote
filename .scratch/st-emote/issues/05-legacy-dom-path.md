# 05 — 旧版本兼容路径与产出统一

**What to build:** 用旧版 ST 的用户（1.15.0–1.18.x，没有官方消息格式化钩子）能看到与新版完全一样的表情：同样的位置、同样的尺寸、同样的类名。关闭扩展或改动设置后，聊天里的图能干净地还原，反复重渲染不会叠加。

**Blocked by:** 04 — 投放方式与尺寸

**Status:** ready-for-agent

- [ ] 在 ST 1.15.0–1.18.x 上，01–04 的全部渲染行为（标记形态、命中规则、未命中、投放方式、尺寸、多张竖排）与 1.19.0 以上的表现一致
- [ ] 两条路径产出的元素带同一个类名与同一组 `data-*` 标识，样式只需维护一份
- [ ] 重渲染、加载更早的消息（Show more）、swipe 切换、编辑消息之后，不出现重复插图或残留旧图
- [ ] 关闭扩展后，聊天里的图恢复为原始标记文本
- [ ] 两条路径用同一套断言口径校验（只断言最终 DOM 的结构、类名与尺寸样式，不断言实现方式）
