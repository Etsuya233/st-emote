# 不复用官方 Sprites 接口

官方 `/api/sprites/*` 是内置 Character Expressions 扩展的专属接口，读写的就是角色的立绘槽位目录，它的 `get` 会为该目录里每个图片文件生成一个立绘槽位。本扩展的表情图片因此不走它，改用 ST 自带的上传接口把图片写进用户数据目录。

**Considered Options**：复用 `/api/sprites/*`（被否：两个特性的数据与 UI 会互相污染，表情会出现在立绘抽屉里）；新增服务端插件提供专用目录（被否：要求用户额外安装服务端组件，而这个扩展没有必须服务端的理由）。

**Consequences**：表情文件会与其它特性的文件混放，实现时必须挑污染最小的目录、用文件名前缀区分归属，并且绝不删除非本扩展创建的文件（见 ADR-0003）。
