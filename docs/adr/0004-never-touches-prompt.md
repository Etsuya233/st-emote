# 扩展不修改用户提示词

标签清单通过注册宏 `{{st-emote}}` 提供，由用户自己写进预设、世界书或角色卡字段；扩展不使用 `setExtensionPrompt` 之类的注入机制，也不往预设里塞任何文本。代价是用户必须自己动手写一次宏，收益是提示词完全由用户掌控。

**Considered Options**：用 `setExtensionPrompt` 自动注入（被否：与宏并存时最典型的事故是标签表在提示词里出现两遍，而用户要在预设和扩展两处排查；去掉它之后"扩展不碰提示词"是一条干净、可解释的边界）。

**Consequences**：清单内容必须能在提示词构建时实时计算（用户启用新包后下一轮即生效，不需要任何刷新动作）；宏打错名字时 ST 会把字面量留在提示词里，这是可见的、可接受的失败方式。
